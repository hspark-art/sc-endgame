1. 지금 데이터 규모

```bash
python3 -c "
import json
for f,label in [('data/endgame.json','끝장전'),('data/asl.json','ASL')]:
    g=json.load(open(f))['global']
    print(label, g)
"
```

3. 아직 올리지 않은 변경이 있는지 — `python3 tools/deploy.py --dry-run`

4. 저장소 상태 — `git status --short`
